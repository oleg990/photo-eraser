# Фото-Ластик

Веб-приложение для iPhone (и любого телефона) для подготовки фото квартир к рекламе:
- **свет и цвет** улучшаются сами при добавлении фото;
- **лишнее убирается** тремя способами: кистью, «Авто» с проверкой или полностью автоматически;
- всё считается на самом телефоне, фото никуда не отправляются; после первого запуска работает без интернета.

## Установка (один раз)

1. На компьютере в папке проекта:
   ```
   python setup.py --auto
   ```
   - движок и модель стирания LaMa (~110 МБ);
   - детектор лишних предметов для авто-уборки (`--auto`): ставит `ultralytics` с PyTorch (~2 ГБ, только на ПК, один раз) и собирает `models/detector.onnx` (~50 МБ).
   Без `--auto` приложение работает только с кистью.
   Если модель LaMa не скачалась (Hugging Face), скрипт подскажет, откуда взять файл вручную (может понадобиться VPN).
2. Проверка на компьютере: `python -m http.server 8000` → `http://localhost:8000`.
3. Публикация (нужен https, иначе iPhone не даст сохранять и ставить на экран):
   - создайте репозиторий на GitHub и загрузите все файлы через `git push` (модель 92 МБ влезает в лимит 100 МБ, через сайт не загрузить);
   - Settings → Pages → Deploy from branch → `main` / root;
   - адрес будет вида `https://oleg990.github.io/<имя-репозитория>/`.
4. На iPhone откройте адрес в Safari → «Поделиться» → «На экран “Домой”». Первый запуск делайте по Wi-Fi: загрузится ~160 МБ, дальше всё из кэша.

## Как пользоваться

| Кнопка | Что делает |
|---|---|
| **+ Фото** | выбрать снимки из галереи (сразу улучшаются, если включено) |
| **Кисть** | выделите предмет пальцем (можно несколькими мазками), затем нажмите **Удалить**. Двумя пальцами приближать, двойной тап показывает весь кадр |
| **Авто** | находит людей, обувь, одежду, сумки, бутылки, коробки, провода и т. п. и показывает рамками. Тап по рамке переключает «убрать / оставить». Можно докрасить кистью. Затем «Удалить» |
| **До/после** | удерживайте, чтобы увидеть оригинал |
| **↶ Назад / Вперёд ↷** | шаги по процессу: пока не нажали «Удалить», убирают и возвращают мазки по одному; после — откатывают и возвращают удаление или улучшение |
| **Сохранить / Сохранить все** | меню iPhone → «Сохранить изображение» |

Настройки (⚙):
- **Улучшать при добавлении**: вкл/выкл.
- **Удалять сразу после выделения**: по умолчанию выключено (сначала выделяете, потом «Удалить»).
- **Полностью автоматически**: при добавлении фото приложение само улучшит, найдёт и сотрёт лишнее во всех кадрах. Кнопка «Остановить» прерывает процесс. Порог уверенности здесь строже, чем в «Авто», чтобы не стирать лишнего.
- **Что убирать автоматически**: группы предметов.
- **Авто-уборка всех фото сейчас**: для уже добавленных снимков.
- **Ускорение видеокартой (тест)**: WebGPU, если поддерживается. При ошибках выключите.

## Скорость

- Движок работает в несколько потоков (до 4). Включается сам после первой загрузки: страница один раз перезагрузится.
- Модель загружается заранее, как только добавлены фото, поэтому первое стирание не ждёт загрузки.
- Каждый найденный предмет стирается отдельно: так качественнее, чем одним большим куском.
- Ориентир на iPhone: поиск лишнего около 1 с на фото, стирание предмета несколько секунд (зависит от модели телефона).

## Ограничения

- Детектор находит предметы, но не «общий бардак». Кучи вещей и мелочь на узорных поверхностях проще закрасить кистью.
- Большие области (больше примерно трети кадра) стираются хуже: убирайте их по частям.
- Автоматику всегда проверяйте через «До/после».
- Реальные дефекты квартиры (отклеенные обои, пятна, трещины) скрывать не стоит: покупатель увидит их на просмотре.

## Для разработчика

- `index.html`, `app.js` (всё приложение), `sw.js` (офлайн-кэш и заголовки COOP/COEP для многопоточности), `setup.py`.
- Параметры в адресе: `?mock=1` подставляет заглушки вместо нейросетей (проверка интерфейса), `?gpu=1` пробует WebGPU.
- LaMa (`Carve/LaMa-ONNX`): вход `image` [1,3,512,512] 0..1 и `mask` [1,1,512,512], выход 0..255. Стирание идёт по квадратному окну с запасом контекста, результат вставляется в полном разрешении с мягким краем и подгонкой тона.
- Детектор: YOLO-World v2 с зашитым словарём (см. `AUTO_CLASSES` в `setup.py` и `GROUPS` в `app.js`, порядок должен совпадать). Модель другую можно выбрать так: `DET_MODEL=yolov8m-worldv2.pt python setup.py --auto`.
